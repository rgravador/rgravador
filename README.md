## About

Full-stack engineer with a bias toward **TypeScript** and **Vue / Nuxt**. I build products end-to-end - from schema design to the UI layer. Six-plus years of shipping things that work in production.

Currently at **[8x8](https://8x8.com)**, a global cloud communications platform. On the side, building **[GigsBook PH](https://gigsbookph.com)** - a full-stack events marketplace for the Philippines.

I care about clean APIs, type safety, pragmatic architecture, and not shipping broken UI.
